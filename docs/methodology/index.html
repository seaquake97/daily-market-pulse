研判方法论 · Methodology

每日市场脉搏的全部结论由 daily-decision-engine 决策引擎按确定性流程产出：数据硬校验 → 代码化信号评分 → 专家圆桌对抗辩论 → Σ 评级。
All conclusions are produced by a deterministic pipeline: validated data → code-computed signals → adversarial expert roundtable → Sigma rating.

  1. 交易日判定：经交易日历确认目标日为 A 股交易日；非交易日静默结束，不产出。
  2. 数据采集：行情、板块资金、涨跌分布、估值等全部经腾讯自选股 MCP（westock-mcp）实时获取，禁止写死数值或凭记忆填数。
  3. 信号评分：S1-S6 六信号由代码计算并合入 verdict 字段，LLM 禁止手工调分。
  4. 持仓解析：持仓与网格参数从本地记忆文件动态解析，代码与提示词中不写死任何持仓数据。
  5. 硬校验：数据完整性断言任一失败即停产出，标注缺口清单，禁止带脏数据出报告。
  6. 专家研判：六位虚拟专家（产业/信号/估值/逆向/财报/短线维度）多空对抗辩论，观点须引用当日数据。
  7. 决策卡落档：结构化决策卡与观点台账归档，供后续准确率结算与连续错误熔断。

二、S1-S6 确定性信号评分 / Signal Scoring

六信号全部由代码计算，缺失信号自动从归一化权重中剔除；Σ 为加权求和，范围 [-1, +1]。

信号维度权重输入口径计算逻辑（简化）
S1量能 Volume0.20沪指量比（相对过去 5 日同时段归一化）clamp((量比-1.0)/0.8)
S2宽度 Breadth0.20上涨占比、涨停/跌停家数宽度项 0.7 + 涨跌停项 0.3
S3动量 Momentum0.15上证 vs MA5/MA20 + 20 日涨跌幅均线偏离 0.5+0.5 与 20 日涨幅平均
S4分化 Dispersion0.15创业板指+科创50 均值 vs 沪深300clamp(价差/2.0)
S5资金 Flows0.15板块主力净流入 TOP1 - 净流出 TOP1clamp(净差/50亿)
S6估值 Valuation0.15沪深300 PE + 60 日涨跌幅（超跌代理）clamp((15-PE)/3 + 超跌项 0.5)
有效权重封顶规则（v1.2）：有效权重 < 0.50（过半信号缺失）时，评级强制封顶为「信号矛盾」并标记数据不足——单一信号不得主导方向性结论。

三、Σ 评级五档 / Sigma Rating Tiers

评级Σ 区间操作含义
▲▲ 进攻≥ +0.50做多窗口：定投上浮 ≤20%、网格卖档上移、新增买入 ≤ 总仓位 5%
▲ 均衡+0.15 ~ +0.50基准定投 + 网格原参数，不主动加减仓
↔ 信号矛盾-0.15 ~ +0.15暂停主动买入；只列多空证据 + 明日待验证信号，禁止给方向
▼ 防守-0.50 ~ -0.15暂停主动买入、定投可降 ≤30%、只挂更低吸买单
▼▼ 回避≤ -0.50定投暂停一期、浮亏 >15% 品种分笔减 ≤1/3、防御仓再平衡

评级徽章采用色相 + 箭头双重编码（色盲友好）。箭头 ▲▲/▲/↔/▼/▼▼ 与色阶分离：箭头表方向强度，颜色仅区分档位，不与涨跌语义混淆。

行情颜色惯例：本站行情数字遵循中国市场惯例 红涨 / 绿跌（红为上涨、绿为下跌），仅用于行情数值呈现；评级档位不用红绿表方向。

四、反滥用设计 / Anti-Abuse Design

  • 代码计算 Σ：Σ 由代码写入数据文件的 verdict 字段，报告引用必须原样呈现，禁止四舍五入或改述。
  • LLM 禁调分：语言模型不得修改任何信号分值，研判文本只解释代码结论。
  • 零编造：数据缺失明确标注「数据缺口」并降级，禁止用代理指标伪装真实值。
  • 信息隔离：持仓数据不参与信号评分输入，避免禀赋效应污染方向判断。
  • 观点台账：全部历史观点归档结算，连续错误触发熔断降级。

五、数据来源与隐私 / Data & Privacy

  • 数据来源：腾讯自选股 MCP（westock-mcp）实时采集的行情、板块资金、涨跌分布与估值数据。
  • 数据时点：每期报告头部标注（竞价 / 盘中 / 收盘），不同时点的结论不可直接对比。
  • 隐私边界：公开版本报告仅包含市场数据、信号评分与方法论；个人持仓金额、成本、盈亏与账户信息在发布前经自动化脱敏流水线移除，并经红线门禁校验（零命中方可发布）。
